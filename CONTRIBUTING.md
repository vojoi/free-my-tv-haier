# Участие в разработке

Проект — адаптация [Free My TV](https://github.com/simbasjungles/free-my-tv) под Android TV Haier. Изменения для других моделей и версий Android требуют проверки на соответствующем устройстве.

1. Создайте ветку с конкретным исправлением.
2. Сохраните Java 8, отсутствие сторонних библиотек и существующий Canvas-рендеринг.
3. Соберите Android APK: `./build-windows.ps1 -Public` в PowerShell или `./build.sh` в Linux/macOS.
4. Для интерфейсных изменений приложите скриншот; для навигации проверьте пульт, запуск приложений и возврат из заставки.
5. Не добавляйте API-ключи, `config.properties`, сертификаты подписи, адреса личных устройств и диагностические дампы.

Не меняйте настройки изображения, звука и сети телевизора при исправлении лаунчера. Сохраняйте режим «Оригинальный» и watchdog. Новые источники изображений должны иметь документированные права использования; авторов фотографий указывайте в `app/assets/gallery/CREDITS.md`.

Для сообщения об ошибке достаточно модели телевизора, версии Android, шагов воспроизведения и ожидаемого результата. Удаляйте токены и персональные данные из логов.
