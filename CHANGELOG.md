# Изменения адаптации

## Первая публичная версия

Основа: `simbasjungles/free-my-tv`, коммит `62e883b3179c8cafb7a2b09960eabfe7eea6ef1c`.

- Нативные рекомендации и переходы к конкретным названиям в Кинопоиске, Okko и Иви для российского региона.
- Большой горизонтальный баннер 16:9 и согласованные дополнительные карточки.
- Стеклянные часы в верхней части главного экрана; увеличенный логотип Кинопоиска.
- Курсы USD/RUB и EUR/RUB ЦБ РФ вместо криптовалют на Android.
- Независимая заставка с шестью встроенными фотографиями природы, плавной сменой, движением кадра и смещением часов.
- Ограниченный DNS fallback для API погоды/TMDB с проверкой исходного TLS-имени.
- Адаптация смены главного экрана для Haier без дополнительного списка отключаемых приложений.
- Переносимая сборка Windows, пример конфигурации без ключей и описание публичной сборки.

Унаследованные веб-версии, LG webOS и Samsung Tizen сохранены как исходники upstream. Перечисленные изменения интерфейса относятся к Android.
